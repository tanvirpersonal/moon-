# Moonflight — Rocket Builder

A code-only browser spaceflight prototype inspired by rocket-building simulators.

## Play

Serve the repository with any static web server, or enable GitHub Pages for the `main` branch root.

## Current prototype

- 3D rocket assembly bay
- Modular capsule, nose, tanks, engines, boosters, fins and decouplers
- Click-to-add vertical rocket construction
- Live mass, fuel, thrust and TWR calculations
- Moon launch scene
- Throttle and staging controls
- Simplified lunar gravity / thrust / fuel simulation
- Altitude, velocity, fuel and mission-time HUD
- Three.js via CDN; no generated art assets required

## Roadmap

Next iterations can add true part attachment points, side boosters, staging graphs, orbital mechanics, procedural lunar terrain, landing legs, RCS, save/load, multiple celestial bodies and a more advanced flight editor.
